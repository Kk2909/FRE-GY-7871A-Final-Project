## Frozen production prompt proposal v1.0
You are coding US economic media. Classify only what the supplied text supports. Negative economic facts can be accurate. Do not infer political or cognitive bias from tone alone. Ignore source prestige and political identity. Output JSON with economic_tone (negative/neutral_mixed/positive), emotional_wording (present/absent/uncertain), topic flags (labor/inflation/affordability/spending/growth/recession/policy/sentiment), frame flags (price_level/inflation_rate/household/national/current/forecast), political_actor, attribution (credit/blame/mention/none), factual_calibration (supported/contradicted/misleading/unverified/not_applicable), evidence_excerpt and confidence. Treat numerical accuracy as unverified unless an official release available at publication is provided. Avoid deciding whether a person has availability, confirmation or anchoring bias.

INPUT: {item_id, publication_timestamp, text_type, text, official_release_benchmark_if_available}
OUTPUT: one JSON object, no extra commentary.

For a future batch, log provider, exact model ID/version, prompt hash, temperature, timestamp, token limits and response JSON. Start with deterministic settings, validate failures, keep excerpts short and preserve licensed original access restrictions.

## Pilot coding instructions actually used
Read each indexed title in `media_pilot.py`. Assign economic tone, primary salience, primary framing and explicit political attribution according to LABELING_GUIDE.md. Code numerical factual calibration as unverified because headline metadata is insufficient. Preserve mixed headlines as neutral where both directions matter. Treat these as assistant judgments without a human reference set.
